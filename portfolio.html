MY SMART CAMPUS

TECH STACK UTAMA:

HTML & CSS3 jQuery (JavaScript SPA) Progressive Web App (PWA) GitHub REST API

FITUR APLIKASI YANG DIKEMBANGKAN:

  • Mobile UI Foundation: Dilengkapi splash screen interaktif dan bottom navigation bar ala aplikasi native.
  • SPA Navigation: Alur perpindahan menu dinamis tanpa reload penuh memanfaatkan AJAX.
  • Smart Schedule & Tugas: Pengingat otomatis mata kuliah harian dan deadline tugas.
  • PWA Integration: Dapat diinstal langsung di layar utama smartphone serta mendukung mode offline.
  • Online/Offline Sync: Sinkronisasi status data otomatis mendeteksi kondisi jaringan perangkat.
