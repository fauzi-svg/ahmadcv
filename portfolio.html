My Smart Campus Mobile

Project UAS Pemrograman Web Mobile

Aplikasi sistem informasi akademik berskala mini yang dirancang khusus dengan pendekatan Mobile-First Design. Mengimplementasikan arsitektur SPA (Single Page Application) untuk menjamin navigasi cepat, efisien, dan mulus tanpa muat ulang halaman. Aplikasi ini membantu mahasiswa mengelola jadwal kuliah, memantau tugas harian, dan menerima notifikasi penting secara seketika.

AKSES LANGSUNG FITUR APLIKASI:

✨
Splash Screen

Tampilan awal & animasi loading aplikasi.
📊
Dashboard & IPK

Simulasi perolehan nilai & rangkuman akademik.
🔍
QR Scanner

Modul pemindaian presensi berbasis kode QR.

TECH STACK UTAMA:

HTML5 & CSS3 jQuery (JavaScript SPA) Progressive Web App (PWA) GitHub REST API

FITUR APLIKASI YANG DIKEMBANGKAN:

  • Mobile UI Foundation: Dilengkapi splash screen interaktif dan bottom navigation bar ala aplikasi native.
  • SPA Navigation: Alur perpindahan menu dinamis tanpa reload penuh memanfaatkan AJAX.
  • Smart Schedule & Tugas: Pengingat otomatis mata kuliah harian dan deadline tugas.
